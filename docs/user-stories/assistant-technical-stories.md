## Historias Técnicas

| Epic / Story ID | Título | Descripción | Criterios de Aceptación | Relacionado con (Epic ID) |
| --------------- | ------ | ----------- | ----------------------- | ------------------------- |
| WS-US-57           | Enviar Pregunta al Asistente IA | Como Desarrollador, quiero enviar la pregunta de un usuario al asistente a través de una API, para que el modelo de lenguaje responda con el contexto de sus dispositivos, lecturas, umbrales y alertas activas. | Escenario: Enviar pregunta exitosamente<br>Dado que el endpoint "/api/v1/assistant/messages" está disponible<br>Cuando un usuario autenticado envía una petición POST con `content` (1 a 1000 caracteres), `locale` opcional (`es` o `en`) y `conversationId` opcional<br>Entonces se recibe una respuesta con estado 200 con la pregunta y la respuesta almacenadas y el cupo restante del día.<br><br>Escenario: Enviar pregunta inválida<br>Dado que el endpoint "/api/v1/assistant/messages" está disponible<br>Cuando se envía una petición POST con `content` vacío, de más de 1000 caracteres o con un `locale` no soportado<br>Entonces se recibe una respuesta con estado 400.<br><br>Escenario: Continuar una conversación ajena<br>Dado que el endpoint "/api/v1/assistant/messages" está disponible<br>Cuando se envía una petición POST con un `conversationId` que pertenece a otro usuario<br>Entonces se recibe una respuesta con estado 404.<br><br>Escenario: Modelo de lenguaje no disponible<br>Dado que el proveedor del modelo falla o no está configurado<br>Cuando se envía una petición POST válida<br>Entonces se recibe una respuesta con estado 503 y no se almacena ningún mensaje ni se consume cupo. | WS-EP-11 |
| WS-US-58           | Limitar Mensajes Diarios del Asistente por Plan | Como Desarrollador, quiero limitar la cantidad de preguntas diarias al asistente según el plan del usuario, para controlar el costo del modelo y diferenciar el plan Premium. | Escenario: Consultar el cupo del día<br>Dado que el endpoint "/api/v1/assistant/usage" está disponible<br>Cuando un usuario autenticado envía una petición GET<br>Entonces se recibe una respuesta con estado 200 con `used`, `limit`, `remaining`, `resetsAt` y `plan`; el límite es 10 para FREEMIUM y 100 para PREMIUM y se reinicia a la medianoche de America/Lima.<br><br>Escenario: Superar el cupo diario<br>Dado que el usuario ya envió todas las preguntas que su plan permite hoy<br>Cuando envía una petición POST a "/api/v1/assistant/messages"<br>Entonces se recibe una respuesta con estado 429 con la cabecera `Retry-After` y el modelo no es consultado. | WS-EP-11 |
| WS-US-59           | Consultar Historial de Conversaciones del Asistente | Como Desarrollador, quiero listar las conversaciones de un usuario con el asistente y sus mensajes a través de una API, para que pueda retomar una conversación anterior. | Escenario: Listar conversaciones<br>Dado que el endpoint "/api/v1/assistant/conversations" está disponible<br>Cuando un usuario autenticado envía una petición GET con `page` y `size` (máximo 50)<br>Entonces se recibe una respuesta con estado 200 con sus conversaciones ordenadas de la más reciente a la más antigua.<br><br>Escenario: Obtener los mensajes de una conversación<br>Dado que el endpoint "/api/v1/assistant/conversations/{conversationId}/messages" está disponible<br>Cuando el dueño de la conversación envía una petición GET<br>Entonces se recibe una respuesta con estado 200 con los mensajes en el orden de la conversación.<br><br>Escenario: Obtener los mensajes de una conversación ajena<br>Dado que el endpoint "/api/v1/assistant/conversations/{conversationId}/messages" está disponible<br>Cuando se envía una petición GET para una conversación de otro usuario<br>Entonces se recibe una respuesta con estado 404. | WS-EP-11 |
| WS-US-60           | Calificar Respuesta del Asistente | Como Desarrollador, quiero registrar si una respuesta del asistente le fue útil al usuario a través de una API, para medir la calidad de las respuestas. | Escenario: Calificar una respuesta<br>Dado que el endpoint "/api/v1/assistant/messages/{messageId}/feedback" está disponible<br>Cuando el dueño de una respuesta del asistente envía una petición PUT con `rating` igual a `UP` o `DOWN`<br>Entonces se recibe una respuesta con estado 204 y la calificación queda almacenada.<br><br>Escenario: Calificar una pregunta o un mensaje ajeno<br>Dado que el endpoint "/api/v1/assistant/messages/{messageId}/feedback" está disponible<br>Cuando se envía una petición PUT para un mensaje del usuario o de otro usuario<br>Entonces se recibe una respuesta con estado 404. | WS-EP-11 |
