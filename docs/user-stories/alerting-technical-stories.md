# Historias de Usuario - Alertas (Alerting)

| --------------- | ------ | ----------- | ----------------------- | ------------------------- |

## Historias Técnicas

| Epic / Story ID | Título | Descripción | Criterios de Aceptación | Relacionado con (Epic ID) |
| --------------- | ------ | ----------- | ----------------------- | ------------------------- |
| WS-US-34           | Obtener Alertas del Usuario | Como Desarrollador, quiero obtener la lista de alertas del usuario autenticado a través de una API, para poder visualizarlas en el panel de notificaciones principal. | Escenario: Obtener alertas asociadas a los dispositivos del usuario de forma exitosa<br>Dado que el endpoint "/api/v1/alerts" está disponible<br>Cuando se envía una petición GET por parte de un usuario autenticado con parámetros opcionales de estado `status`, `page` y `size`<br>Entonces se recibe una respuesta con estado 200 y una lista paginada de recursos de alertas ordenada por fecha descendente. | WS-EP-06 |
| WS-US-35           | Obtener Resumen Diario de Alertas del Usuario | Como Desarrollador, quiero obtener un resumen diario de ocurrencia de alertas del usuario a través de una API, para alimentar gráficos de volumen de fallos históricos. | Escenario: Obtener resumen diario de alertas de forma exitosa<br>Dado que el endpoint "/api/v1/alerts/daily-summary" está disponible<br>Cuando se envía una petición GET por parte de un usuario autenticado con el parámetro opcional `days`<br>Entonces se recibe una respuesta con estado 200 y una lista de agregaciones diarias con campos de fecha y cantidad de alertas. | WS-EP-06 |
| WS-US-36           | Obtener Alertas por Dispositivo | Como Desarrollador, quiero obtener las alertas pertenecientes a un dispositivo específico a través de una API, para permitir diagnósticos detallados por hardware en la aplicación cliente. | Escenario: Filtrar alertas por dispositivo de forma exitosa<br>Dado que el endpoint "/api/v1/devices/{deviceId}/alerts" está disponible<br>Cuando se envía una petición GET con un `deviceId` perteneciente al usuario autenticado, `page` y `size`<br>Entonces se recibe una respuesta con estado 200 y los registros de alertas del dispositivo.<br><br>Escenario: Intentar obtener alertas de un dispositivo que pertenece a otro usuario<br>Dado que el endpoint "/api/v1/devices/{deviceId}/alerts" está disponible<br>Cuando se envía una petición GET para un `deviceId` ajeno al usuario autenticado<br>Entonces se recibe una respuesta con estado 403. | WS-EP-06 |
| WS-US-37           | Obtener Alertas por Espacio | Como Desarrollador, quiero obtener las alertas de un espacio a través de una API, para que los usuarios puedan identificar problemas en ubicaciones físicas particulares. | Escenario: Filtrar alertas por espacio de forma exitosa<br>Dado que el endpoint "/api/v1/spaces/{spaceId}/alerts" está disponible<br>Cuando se envía una petición GET con un `spaceId` perteneciente al usuario autenticado, `page` y `size`<br>Entonces se recibe una respuesta con estado 200 y las alertas del espacio.<br><br>Escenario: Intentar obtener alertas de un espacio ajeno<br>Dado que el endpoint "/api/v1/spaces/{spaceId}/alerts" está disponible<br>Cuando se envía una petición GET para un `spaceId` que no pertenece al usuario autenticado<br>Entonces se recibe una respuesta con estado 403. | WS-EP-06 |
| WS-US-38           | Obtener Resumen Diario de Alertas por Espacio | Como Desarrollador, quiero obtener el resumen diario agregador de alertas de un espacio a través de una API, para alimentar los gráficos de métricas físicas locales. | Escenario: Obtener resumen diario del espacio exitosamente<br>Dado que el endpoint "/api/v1/spaces/{spaceId}/alerts/daily-summary" está disponible<br>Cuando se envía una petición GET con un `spaceId` válido y del usuario autenticado, y el parámetro `days`<br>Entonces se recibe una respuesta con estado 200 conteniendo los registros agregados.<br><br>Escenario: Obtener resumen diario de espacio ajeno<br>Dado que el endpoint "/api/v1/spaces/{spaceId}/alerts/daily-summary" está disponible<br>Cuando se envía una petición GET para un `spaceId` que no pertenece al usuario autenticado<br>Entonces se recibe una respuesta con estado 403. | WS-EP-06 |
