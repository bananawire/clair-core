| WS-US-40           | Transmitir Telemetría en Vivo mediante SSE | Como Desarrollador, quiero establecer un canal de Server-Sent Events (SSE) para un dispositivo a través de una API, para transmitir flujos de datos en tiempo real al navegador. | Escenario: Establecer transmisión SSE exitosamente<br>Dado que el endpoint "/api/v1/analytics/devices/{deviceId}/live/stream" está disponible<br>Cuando se inicia una conexión GET con tipo de medio `text/event-stream`<br>Entonces se recibe una respuesta con estado 200 y el canal SSE queda establecido. | WS-EP-07 |
| WS-US-41           | Obtener Métricas Históricas | Como Desarrollador, quiero consultar métricas de rendimiento históricas agrupadas por períodos a través de una API, para permitir análisis retrospectivos del entorno físico. | Escenario: Obtener métricas históricas del dispositivo<br>Dado que el endpoint "/api/v1/analytics/devices/{deviceId}/historical" está disponible<br>Cuando se envía una petición GET con los parámetros de consulta `period`, `startDate` y `endDate`<br>Entonces se recibe una respuesta con estado 200 y los KPI agregados del rango solicitado.<br><br>Escenario: Consulta histórica con rango de fechas inválido<br>Dado que el endpoint "/api/v1/analytics/devices/{deviceId}/historical" está disponible<br>Cuando se envía una petición GET donde `startDate` es cronológicamente posterior a `endDate`<br>Entonces se recibe una respuesta con estado 400. | WS-EP-07 |

| WS-US-43           | Obtener Resumen General de Analíticas | Como Desarrollador, quiero obtener una vista global unificada de espacios, dispositivos y alertas recientes a través de una API, para renderizar la página principal del dashboard del usuario. | Escenario: Recuperar resumen general del dashboard exitosamente<br>Dado que el endpoint "/api/v1/analytics/overview" está disponible<br>Cuando se envía una petición GET por parte de un usuario autenticado con los parámetros opcionales `deviceLimitPerSpace` y `alertLimit`<br>Entonces se recibe una respuesta con estado 200 conteniendo el desglose general de espacios, estados de dispositivos y últimas alertas. | WS-EP-07 |
